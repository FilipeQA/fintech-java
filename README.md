# Fintech Java

Projeto acadêmico desenvolvido em Java para a FIAP.

## Objetivo

Aplicar conceitos básicos de Programação Orientada a Objetos.

## Conceitos utilizados

- Classes e objetos
- Métodos
- Encapsulamento
- Construtores
- Herança
- Polimorfismo

## Estrutura

- `Client`: representa o cliente da fintech.
- `Account`: representa uma conta.
- `CheckingAccount`: representa uma conta corrente.
- `SavingsAccount`: representa uma conta poupança.
- `Main`: executa e testa o sistema.

## Execução

O projeto pode ser executado pela classe `Main`.
